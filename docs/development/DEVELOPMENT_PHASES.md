# Development Phases

Effort estimates are person-hours for one developer using Codex, excluding vendor procurement, statutory advice, and prolonged external approvals. Estimates include implementation and phase-level verification, not an arbitrary contingency. Add 20–25% schedule buffer. Web/mobile work is shown in every phase, including explicit deferral where no client feature is needed.

## Cross-phase definition of done

Code is reviewed; required tests pass; migration is forward-only and documented; API/OpenAPI and user documentation are updated; authorization and tenant tests cover new paths; logs contain no secrets/avoidable PII; feature has loading/empty/error behavior; metrics and operational implications are understood; acceptance criteria demonstrated in the target environment.
